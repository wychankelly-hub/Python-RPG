# ⚔️ Python 勇者傳說

用 Python 咒語拯救王國！一個給 Python 初學者的角色扮演 (RPG) 網頁遊戲。

## 🎮 這是甚麼遊戲？

怪物襲擊村莊，你要跟**魔法導師**學習**魔法咒語**，一路打倒怪物，最後挑戰魔王。
這些魔法咒語其實就是真正的 **Python 程式 (program)**！

- 遊戲在瀏覽器裏執行**真正的 Python**（使用 Pyodide），不需要安裝任何軟件。
- 所有介面、故事、提示和錯誤訊息都是**繁體中文**，學生只需要打英文程式碼。
- 需要用到的英文字和符號，全部都會在畫面上顯示（咒語卷軸或字詞庫），把滑鼠移到字詞上就會看到中文意思。
- 打錯了也不用怕：魔法導師會用中文告訴你錯在**第幾行**，以及怎樣修正。
- 戰鬥畫面會跟著你的程式變化：變數變成 HP 條、迴圈每轉一圈就攻擊一次、你寫的函數會變成戰鬥按鈕。

## 👩‍🎓 適合誰？

- 14–15 歲、**完全沒有寫過程式**的初學者
- 看得懂繁體中文，但英文不太好的同學
- 不需要懂得打中文字，只需要用鍵盤打英文和符號

每一章是一節 45 分鐘的電腦課：大約 25–30 分鐘完成 6 個任務，做得快的同學還有 2 個 ⭐ 額外挑戰。

## 🌐 怎樣開始玩？

用 **Google Chrome** 或 **Microsoft Edge** 打開遊戲網址（GitHub Pages）：

**https://你的GitHub帳號.github.io/你的repo名稱/**

> 老師：把 `index.html` 放在 GitHub repo 的根目錄，然後在 repo 的
> **Settings → Pages** 選擇 `main` branch，就會得到上面格式的網址。
> 整個遊戲只有 `index.html` 一個檔案，也可以下載後直接用瀏覽器打開。

⏳ **第一次載入需要大約 20–30 秒**（要下載 Python 魔法書），請耐心等候。之後再開會快很多。

## 🗺️ 五個章節

| 章節 | 地點 | 學習內容 | 章節徽章 |
|---|---|---|---|
| 第 1 章 | 🏡 新手村 | 變數 (variable) 與 `print` | 📦 變數見習生 |
| 第 2 章 | 🌲 迷霧森林 | 條件 `if` / `else` 與比較符號 `>` `<` `>=` `<=` `==` | 🌲 森林判斷師 |
| 第 3 章 | 🕳️ 黑暗洞窟 | `while` 迴圈 (loop) | 🔁 洞窟循環者 |
| 第 4 章 | 🗼 魔法塔 | 函數 (function)、參數 (parameter)、傳回 (return) | 🧙 魔法塔術士 |
| 第 5 章 | 🏰 魔王城 | 總複習：一步一步寫出自己的最終戰鬥程式，打倒魔王 | 👑 Python 勇者 |

完成一章後，下一章才會在地圖上開放。完成第 5 章後，可以取得印有自己名字、等級和徽章的**結業證書**，記得截圖留念！

### 任務類型

每個任務都要由**空白的魔法書**開始，親手打出完整的程式（不可以貼上）：

- 📝 **照打**：照著卷軸上的咒語，一個字一個字打出來。
- 🔀 **選擇**：從字詞庫選擇字詞，再打出整段咒語。
- ✍️ **自己寫**：只有中文計劃，自己寫出咒語（可以用 💡 提示，但會扣少少 XP）。
- 🔧 **修正**：咒語裏有一個錯誤 (bug)，找出來並修正它。
- ⭐ **額外挑戰**：給做得快的同學。

第 5 章是總結專題：每個任務會保留你上一個任務寫的程式，你在下面繼續加入新的咒語。

## 💾 存檔碼怎樣用？

- 遊戲會**自動存檔**在這部電腦的瀏覽器裏，下次按「▶ 繼續」就可以。
- 每完成一個任務，遊戲會顯示一個**存檔碼**，例如：

  ```
  HERO-2-4-K7
  ```

  意思是：第 **2** 章、完成了 **4** 個任務、最後兩個字是檢查碼。
- 請把存檔碼**抄在筆記簿上** ✏️。如果在家裏或另一部電腦玩，或者瀏覽器的資料被清除了，
  只要在標題畫面按「💾 讀取存檔碼」，輸入存檔碼，就可以繼續冒險。
- 存檔碼**只記錄進度**，不會記錄名字或任何個人資料。

## 🖥️ 系統要求

- 最新版本的 **Google Chrome** 或 **Microsoft Edge**（效果最好）
- 需要連接互聯網（載入 Python 和字型）；學校網絡要容許 **cdn.jsdelivr.net**
- 請在瀏覽器直接打開遊戲，不要在編輯器或 App 的「預覽視窗」裏打開（預覽視窗通常不能執行 Python）
- 遊戲有音效，可以按右上角的 🔊 關掉
